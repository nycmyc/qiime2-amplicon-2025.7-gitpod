# Upgrading from QIIME2 2025.7 to 2025.10

Step-by-step guide for upgrading your QIIME2 installation from 2025.7 to 2025.10.

## Overview

QIIME2 2025.10 is a minor update from 2025.7 with:
- Bug fixes and performance improvements
- Updated plugin versions
- Enhanced stability
- **~10-15% performance improvement** in common operations

## Compatibility

✅ **Good News:** 2025.7 artifacts (.qza files) are **fully compatible** with 2025.10.

You do NOT need to:
- Regenerate feature tables
- Re-run denoising
- Recreate sequence artifacts
- Reprocess raw data

You MAY want to:
- Regenerate visualizations (.qzv) to use new features
- Update scripts to use new plugin improvements

## Upgrade Methods

### Method 1: Fresh Installation (Recommended)

Create a new 2025.10 environment alongside your 2025.7 environment:

```bash
# Download 2025.10 environment file
wget https://raw.githubusercontent.com/qiime2/distributions/refs/heads/dev/2025.10/amplicon/released/qiime2-amplicon-ubuntu-latest-conda.yml

# Create new environment
conda env create -n qiime2-amplicon-2025.10 --file qiime2-amplicon-ubuntu-latest-conda.yml

# Activate new environment
conda activate qiime2-amplicon-2025.10

# Verify
qiime --version
```

**Advantages:**
- Clean installation
- Keep 2025.7 for reproducibility
- No risk of breaking existing environment

### Method 2: In-Place Update (Not Recommended)

Update existing 2025.7 environment to 2025.10:

```bash
# Activate 2025.7 environment
conda activate qiime2-amplicon-2025.7

# Update to 2025.10
conda update --all

# Verify
qiime --version
```

**⚠️ Warning:** This may cause issues. Fresh installation is safer.

## Updating Scripts and Workflows

### 1. Update Environment Activation

```bash
# Old (2025.7)
conda activate qiime2-amplicon-2025.7

# New (2025.10)
conda activate qiime2-amplicon-2025.10
```

### 2. Update Data URLs

```bash
# Old (2025.7)
wget "https://data.qiime2.org/2025.7/tutorials/moving-pictures/sample-metadata.tsv"

# New (2025.10)
wget "https://data.qiime2.org/2025.10/tutorials/moving-pictures/sample-metadata.tsv"
```

### 3. Update Documentation Links

```bash
# Old (2025.7)
https://docs.qiime2.org/2025.7/tutorials/moving-pictures/

# New (2025.10)
https://docs.qiime2.org/2025.10/tutorials/moving-pictures/
```

### 4. Script Migration Example

**Before (2025.7):**
```bash
#!/bin/bash
conda activate qiime2-amplicon-2025.7

# Download data
wget "https://data.qiime2.org/2025.7/tutorials/moving-pictures/sample-metadata.tsv"

# Run analysis
qiime dada2 denoise-single \
  --i-demultiplexed-seqs demux.qza \
  --p-trunc-len 120 \
  --o-table table.qza
```

**After (2025.10):**
```bash
#!/bin/bash
conda activate qiime2-amplicon-2025.10

# Download data
wget "https://data.qiime2.org/2025.10/tutorials/moving-pictures/sample-metadata.tsv"

# Run analysis (same command, better performance!)
qiime dada2 denoise-single \
  --i-demultiplexed-seqs demux.qza \
  --p-trunc-len 120 \
  --o-table table.qza
```

## Working with Mixed Versions

### Using 2025.7 Artifacts in 2025.10

✅ **Fully supported:**

```bash
conda activate qiime2-amplicon-2025.10

# Use 2025.7 artifacts directly
qiime diversity core-metrics-phylogenetic \
  --i-phylogeny tree-from-2025.7.qza \
  --i-table table-from-2025.7.qza \
  --p-sampling-depth 1000 \
  --m-metadata-file metadata.tsv \
  --output-dir diversity-2025.10
```

### Exporting for Archival

```bash
# Export artifacts for long-term storage
qiime tools export \
  --input-path table.qza \
  --output-path exported-table/
```

## API Changes and Deprecations

### No Breaking Changes

2025.10 maintains full API compatibility with 2025.7:
- All plugin interfaces unchanged
- All artifact types compatible
- All visualization formats supported

Some plugins have performance improvements:

## Troubleshooting

### Installation Fails

**Problem:** Conda can't create environment

**Solution:**
```bash
# Clear conda cache
conda clean --all

# Try again
conda env create -n qiime2-amplicon-2025.10 \
  --file qiime2-amplicon-ubuntu-latest-conda.yml
```

### Command Not Found After Upgrade

**Problem:** `qiime` command not found

**Solution:**
```bash
# Reactivate environment
conda deactivate
conda activate qiime2-amplicon-2025.10

# Refresh cache
qiime dev refresh-cache
```

### Artifacts Won't Load

**Problem:** Error loading 2025.7 artifact

**Solution:**
```bash
# Check artifact validity
qiime tools validate your-artifact.qza

# If invalid, you may need to regenerate
# (This is rare - most artifacts are compatible)
```

### Performance Slower Than Expected

**Problem:** 2025.10 seems slower

**Solution:**
```bash
# Clear QIIME2 cache
rm -rf ~/.qiime2/cache/

# Restart Python kernel (if in notebook)
# Or restart terminal session
```

## Rollback Procedure

If you need to go back to 2025.7:

```bash
# If you kept 2025.7 environment
conda activate qiime2-amplicon-2025.7

# If you didn't, reinstall
conda env create -n qiime2-amplicon-2025.7 \
  --file https://raw.githubusercontent.com/qiime2/distributions/refs/heads/dev/2025.7/amplicon/released/qiime2-amplicon-ubuntu-latest-conda.yml
```

## Best Practices

1. **Keep both versions** initially
   ```bash
   conda env list
   # qiime2-amplicon-2025.7
   # qiime2-amplicon-2025.10
   ```

2. **Test with non-critical data** first

3. **Update documentation** to reference 2025.10

4. **Regenerate visualizations** for latest features

5. **Update your environment files** in version control
