# QIIME2 2025.10 Migration Tools 🔧

Universal migration tools for QIIME2 Amplicon 2025.10 across all platforms.

## Quick Start

```bash
# Check installation
bash migration-scripts/version-check.sh

# Compare platforms
cat PLATFORM_COMPARISON.md

# Upgrade from 2025.7
cat upgrade-guide/FROM_2025.7_TO_2025.10.md
```

## What's Included

- **version-check.sh** - Verify QIIME2 2025.10
- **PLATFORM_COMPARISON.md** - Detailed platform comparison
- **FROM_2025.7_TO_2025.10.md** - Upgrade guide

## Migration Branches

- `github-codespaces-migration` - GitHub Codespaces
- `oracle-cloud-migration` - Oracle Cloud Free Tier
- `colab-migration` - Google Colab
- `binder-migration` - Binder
- `lightning-ai-migration` - Lightning.ai
- `update-to-2025.10` - Gitpod Legacy
